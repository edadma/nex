---
title: "Appendix A: Naming Conventions"
summary: Recommended (but not enforced) conventions for modules, types, functions, and constants.
weight: 200
---

The following naming conventions are recommended but not enforced:

- Module and file names: lowercase, underscore-separated (`linalg`, `dense_matrix`)
- Type names (structs): UpperCamelCase (`Point`, `LineSegment`, `Matrix`)
- Function and binding names: lowercase, underscore-separated (`compute_norm`, `dense_solve`)
- Constants: UPPER_SNAKE_CASE (`PI`, `MAX_ITERATIONS`)
